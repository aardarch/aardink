# Internationalization (i18n)

Aardink resolves UI strings automatically from the platform locale via `EditorStringsRegistry`
(falling back through BCP-47 subtags to English `EditorStringsEn`), or from an explicit
`EditorOptions(languageTag = ...)` / `LocalEditorStrings` provider.

## How to add a new language (5 steps)

1. **Create the translation file** under `editor/src/commonMain/kotlin/com/aardarch/aardink/ui/`,
   implementing `EditorStrings` (for example `EditorStringsEs.kt`):
   ```kotlin
   object EditorStringsEs : EditorStrings {
       override val findPlaceholder: String = "Buscar"
       // ... implement every property and function required by the compiler
   }
   ```
2. **Register the BCP-47 tag** in `EditorStringsRegistry` (`EditorStrings.kt`):
   ```kotlin
   private val languages: Map<String, EditorStrings> = mapOf(
       "en" to EditorStringsEn,
       "pt" to EditorStringsPtBr,
       "pt-br" to EditorStringsPtBr,
       "es" to EditorStringsEs,
   )
   ```
3. **Run the completeness & ABI checks**:
   ```pwsh
   ./gradlew :editor:jvmTest --tests "*EditorStringsTest*"
   ./gradlew updateAbiAll
   ```
4. **Format with Spotless**: `./gradlew :editor:spotlessApply`.
5. **Override from a host app (optional)**: pass a custom `EditorStrings` or load a partial JSON
   override via `CompositionLocalProvider(LocalEditorStrings provides EditorStringsParser.fromJson(json)!!)`.
